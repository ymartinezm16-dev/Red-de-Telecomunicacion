# NetGraph - Versión HTML completa

## Qué incluye
- HTML5
- CSS3
- JavaScript
- Sin MySQL
- Sin servidor
- Sin instalación de dependencias
- Datos persistentes en localStorage

## Cómo ejecutar
1. Descomprime el ZIP.
2. Abre la carpeta `NetGraph_HTML_Completo` en Visual Studio Code.
3. Abre `index.html` en un navegador.
4. Recomendado: instala en VS Code la extensión **Live Server** y selecciona "Open with Live Server".

También puedes abrir `index.html` directamente con Chrome, Edge o Firefox.

## Funciones
1. Inicio y visualización de la red.
2. Registro de servidores.
3. Registro de conexiones.
4. Matriz de adyacencia.
5. Análisis Euleriano.
6. Camino Hamiltoniano.
7. Coloración de grafos para asignación de canales.
8. Comparación por isomorfismo.
9. Análisis completo.

## Datos
Los datos iniciales son cuatro servidores y cinco conexiones. Las modificaciones se guardan automáticamente en el navegador usando localStorage.
